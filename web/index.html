An API that is ready for quantum computers.

OAuth 2.0 tokens signed with ES256 and verified through a rotating JWKS, messages protected with X-Wing (ML-KEM-768 + X25519) hybrid encryption, and every release scanned, signed and attested by the CI/CD pipeline. Everything below runs live against the real API.

The pipeline behind it

      
Every push runs these gates on GitHub Actions. A failing gate blocks the release; the Debian 12 base image was rejected by Trivy for OpenSSL CVEs and replaced.
