# Security policy

Please report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/poke1896/qsafe-gateway/security/advisories/new)
instead of opening a public issue. I aim to acknowledge reports within 72 hours.

Only the latest `main` is supported. Published images are signed with Sigstore; see the README for how to
verify a signature and its build provenance before running an image.
